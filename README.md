A make.fun entry for `u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35`.

The program writes exactly one emoji to `/output/entry.txt`:

> 🏝️ — desert island (U+1F3DD + U+FE0F)

One grapheme, two code points, seven UTF-8 bytes, no trailing newline.

## Why this emoji

The desert island is the archetypal dream vacation in a single glyph: a
faraway tropical island with a palm tree — a wordless postcard. It names
the trip at a glance, is vivid and specific rather than any generic
holiday, and reads instantly across cultures and screens.

## Run

```sh
python3 main.py            # writes /output/entry.txt
python3 main.py out.txt    # optional explicit output path (local check)
```

Deterministic, offline, standard library only. No input is read and the
same bytes are written on every run.
